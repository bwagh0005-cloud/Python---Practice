# AGENTS.md

This folder contains beginner Python practice files focused on core language concepts. Keep changes simple, clear, and educational.

## Working conventions

- Prefer plain Python 3 code and keep examples self-contained.
- Preserve beginner-friendly comments and explanatory output when editing existing learning samples.
- Favor small, single-purpose scripts over abstractions, classes, or frameworks unless the exercise explicitly calls for them.
- Keep filenames aligned to the concept being demonstrated, such as `TUPLES.py` for tuple examples.
- Avoid adding dependencies or tooling unless the task specifically requires them.

## Validation

- Treat scripts in this folder as runnable examples.
- When modifying a script, verify it by running:
  - `python TUPLES.py`
  - or the equivalent for the file you changed
- If a script contains intentional beginner mistakes for learning purposes, do not "fix" them unless the user asks for a corrected version.

## Project context

- This is a practice workspace, not a production app.
- The goal is clarity, teaching value, and correctness of the example itself.
- The current example file is [TUPLES.py](TUPLES.py).
